# The environment of this repository: Python 3.12, CUDA 12.1 builds of
# torch/torchvision, every package (with its dependencies) pinned to the exact
# installed version. Keep numpy and scipy pinned: scipy 1.17+ moves the McNemar
# p-values by about 1e-15.
#
#   python -m venv .venv            (Python 3.12)
#   pip install -r requirements.txt
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#
# The `+cu121` builds come from PyTorch's index (the line below). A plain
# `torch==2.5.1` would resolve to the CPU build, and pip would treat it as
# satisfying this file. On a machine without CUDA 12 drivers, replace `cu121`
# by `cpu` (or another CUDA flavour): the code runs, but the numbers are only
# bit-identical on the same GPU and builds (see README.md, "Reproducibility").
#
# eigenkit (https://github.com/eigenorbit/eigenkit, on PyPI) provides the
# orthogonal layers, the certificate and the losses.
#
# BRONet itself is not a pip package: experiments/bronet_mlp/scripts/setup_bronet.*
# clones ntuaislab/BRONet at commit 9d59c9b and downloads the checkpoint.
